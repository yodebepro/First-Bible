Connect Your Calendar

GOOGLE CALENDAR

1. Download the .ics file above
2. Open calendar.google.com
3. Click ⊕ (Other Calendars) → Import
4. Upload the .ics file

MICROSOFT OUTLOOK

1. Download the .ics file
2. Open Outlook.com or Outlook app
3. File → Open & Export → Import/Export
4. Select "Import an iCalendar file"

APPLE CALENDAR

1. Download the .ics file
2. Double-click it on your Mac or iPhone
3. Calendar app will offer to import it automatically
